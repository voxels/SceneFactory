# Offline ComfyUI voice cloning (macOS Apple Silicon)

Local, no-cloud pipeline: short video → 6–15 s mono reference WAV → Qwen3-TTS 12Hz **1.7B Base** clone → new spoken line as WAV.

This folder is the operator kit. It does **not** touch the live Ad2184 LTX queue. Install nodes and restart ComfyUI only after those jobs finish.

## Stack

| Role | Choice |
|---|---|
| Orchestrator | ComfyUI (this machine’s Desktop instance) |
| Node pack | [diodiogod/TTS-Audio-Suite](https://github.com/diodiogod/TTS-Audio-Suite) |
| Default cloner | `Qwen3-TTS-12Hz-1.7B-Base` |
| A/B engine | F5-TTS **v1 Base** (muted in the workflow until you unmute it) |
| Device | Apple Silicon **MPS** via engine `auto` (`resolve_torch_device("auto")` → `mps`) |
| Precision | **float32** for Base clone. VoiceDesign may use float16. |
| Runtime | Qwen3 **Shared Runtime** (legacy Transformers 4 isolation) |

Not the default: Fish Audio S2 Pro, MOSS-TTS 8B, XTTS-v2, cloud TTS. Optional engines (IndexTTS-2/2.5, Echo-TTS, OmniVoice) are swap-in **engine nodes** on the same `🎤 TTS Text` input; they are not wired in the default graph.

`ai-joe-git/ComfyUI-Qwen3-TTS` is **not** installed. The suite already clones from a reference WAV. Its engine dropdown lists `auto`/`cuda`/`cpu` only; on this Mac `auto` is MPS. Install that second pack only if `auto` falls through to CPU.

## 1. Extract a reference from video

```sh
cd /Users/voxels/SceneFactory/v3/voice_clone
chmod +x extract_reference.sh install.sh download_models.sh
./extract_reference.sh /path/to/clip.mp4 ./voices/on_camera.wav 0 12
```

`ffmpeg` is already on this machine. The script writes PCM s16le, 22050 Hz, mono, duration 6–15 s. Optional start/duration: `./extract_reference.sh clip.mp4 out.wav 8.2 10`.

Use one speaker, dry speech, no music bed. Denoise/vocal isolation in TTS Audio Suite is optional and not required.

Put the exact transcript in `voices/on_camera.reference.txt`, then stage the
canonical pair. This atomically replaces Comfy's reference and generates a
ready workflow with the transcript embedded:

```sh
./stage_into_comfy.sh
```

Load `workflows/qwen3_base_clone_f5_ab.ready.json`, not the transcript-free
template. Qwen3 Base ICL (default, `x_vector_only_mode=false`) and F5-TTS both
need the exact transcript.

Before staging or queueing, run the non-mutating preflight:

```sh
./preflight.sh
./runtime_preflight.sh
```

It validates the installed node pack, complete model weights, PCM16/22050 Hz/mono reference format, 6–15 second duration, exact transcript presence, and staged Comfy input. It never starts Comfy or submits a prompt.

## 2. Install nodes (after Ad2184 jobs)

```sh
export COMFY_ROOT=/Users/voxels/ComfyUI-Installs/ComfyUI/ComfyUI
export COMFY_PYTHON="$COMFY_ROOT/.venv/bin/python"
./install.sh
```

`install.py` is the suite’s own installer. The Comfy Python must be native **arm64**, not Rosetta. Then restart ComfyUI so the nodes load. Do not restart while LTX is still rendering.

## 3. Download Qwen3 1.7B Base (required)

```sh
export COMFY_ROOT=/Users/voxels/ComfyUI-Installs/ComfyUI/ComfyUI
./download_models.sh
```

That pulls:

```text
ComfyUI/models/TTS/qwen3_tts/
  Qwen3-TTS-12Hz-1.7B-Base/          # required cloner
  Qwen3-TTS-Tokenizer-12Hz/          # required tokenizer
```

Optional variants:

```sh
DOWNLOAD_OPTIONAL=1 ./download_models.sh
```

which also fetches `0.6B-Base`, `1.7B-VoiceDesign`, `1.7B-CustomVoice`.

Exact Hub commands if you prefer to run them by hand:

```sh
huggingface-cli download Qwen/Qwen3-TTS-12Hz-1.7B-Base \
  --local-dir "$COMFY_ROOT/models/TTS/qwen3_tts/Qwen3-TTS-12Hz-1.7B-Base"
huggingface-cli download Qwen/Qwen3-TTS-Tokenizer-12Hz \
  --local-dir "$COMFY_ROOT/models/TTS/qwen3_tts/Qwen3-TTS-Tokenizer-12Hz"
```

After that cache, the workflow is offline. F5-TTS v1 Base still auto-downloads on the first **unmuted** F5 run into `models/TTS/F5-TTS/F5TTS_v1_Base/`.

If Comfy Desktop extra-model-paths is used, also place the same tree under `/Users/voxels/ComfyUI-Shared/models/TTS/qwen3_tts/` or add a `TTS:` folder to the extra-paths YAML **after** a restart. The live YAML does not currently declare a TTS folder.

## 4. Load the workflow

File: `workflows/qwen3_base_clone_f5_ab.ready.json` (generated by staging)

Comfy Desktop → Load. Default queue path:

1. Load Audio `voice_clone/reference.wav`
2. Character Voices (transcript + optional trim 0–15 s)
3. ⚙️ Qwen3-TTS Engine — Base 1.7B, `auto`, `float32`, `sdpa`, Shared Runtime
4. 🎤 TTS Text
5. Preview Audio + Save Audio prefix `voice_clone/qwen3_base_clone`

### M2 Max node settings

| Widget | Value | Why |
|---|---|---|
| model_variant | `TTS - Base 1.7B (Voice Clone)` | Required cloner |
| device | `auto` | Resolves to MPS; dropdown has no `mps` entry |
| dtype | `float32` | Base clone NaNs on MPS in fp16/bf16 |
| attn_implementation | `sdpa` | No FlashAttention on Mac |
| x_vector_only_mode | false | ICL uses audio + transcript |
| use_torch_compile | false | CUDA/triton path |
| use_cuda_graphs | false | No CUDA |
| runtime_mode | Shared Runtime | Isolates Qwen3 from Transformers 5 |
| language | English (or Auto) | 10-language Base model |
| seed | any fixed int | Reproducible |

Unload FLUX/LTX workflows from the graph or from VRAM before this run if unified memory is tight (96 GB is enough in principle; two 22B video models plus 1.7B TTS is still a bad idea).

## 5. Swap Qwen3 vs F5-TTS

The F5 group is **muted** (`mode: never`) so a default queue does not load F5.

1. Keep Character Voices connected (same WAV + transcript).
2. Select **F5 TTS Text**, turn bypass/never **off**.
3. Engine is already `F5TTS_v1_Base` on `mps`.
4. Queue. Output prefix: `voice_clone/f5tts_v1_clone`.

To compare other suite engines, unplug the Qwen3 engine from TTS Text and plug ⚙️ IndexTTS / ⚙️ Echo-TTS / ⚙️ OmniVoice instead. Do not make those the default.

## Known Mac issues

- Qwen3 **Base** clone on MPS must be **float32** or generation hits `probability tensor contains inf/nan`.
- VoiceDesign can use float16; this workflow does not use VoiceDesign for cloning.
- First Shared Runtime start can take a long time while the isolated env is created. After that, offline.
- `install.py` / `huggingface_hub` could not be executed into ComfyUI from the sandboxed Scene Factory session. Run `install.sh` and `download_models.sh` in Terminal after the LTX jobs exit. See [`STATUS.md`](STATUS.md).
