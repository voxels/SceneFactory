## Generation gates

- [ ] Project validates.
- [ ] Source index is current.
- [ ] Reference contracts are complete and agree.
- [ ] Character identities are approved.
- [ ] Wardrobes and props are approved.
- [ ] Storyboards/key frames are approved.
- [ ] Pose/motion controls are reviewed.
- [ ] Masks and screen tracks are reviewed.
- [ ] Three-second representative proofs pass.
- [ ] Long clips are authorized.

## Turnover gates

- [ ] Every delivered artifact has a source/workflow hash.
- [ ] Media dimensions, rate, duration, and alpha are inspected.
- [ ] Audio stream count is zero.
- [ ] Only user-approved artifacts enter the edit pool.
- [ ] Rejected candidates remain traceable.
- [ ] Episode manifest is frozen at delivery.
